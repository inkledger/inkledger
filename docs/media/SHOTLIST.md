# Shot list

Screenshots and clips the [README](../../README.md) points to. None exist yet: capture them, save them here under these names, and keep the README's alt texts accurate.

Rules for every capture:

- Demo data only: fictional people, projects, issue keys and hosts. No real tracker URLs, names, emails or company data, in the page or in the browser chrome.
- Light theme unless noted, default density, English UI, 1440 × 900 window at 2× scale.
- WebP for stills (under 300 KB each), MP4 (H.264, no audio, under 4 MB) for clips.
- Crop the browser chrome; no notifications, cursors or personal bookmarks in sight.

| File | Screen | What must show |
| --- | --- | --- |
| `hero.webp` | Dashboard | Day timeline with a running timer, a gap in the afternoon, quick stats, issue list |
| `timeline.webp` | Dashboard, day timeline | Logged blocks from two trackers, a running timer, an overlap shown in lanes |
| `fill-the-gap.webp` | Dashboard, a gap opened | A gap cut into two pieces, each assigned to an issue |
| `timesheet-week.webp` | Timesheet, week | A full week with one closed (locked) week visible in the header |
| `board.webp` | Board | Columns from a tracker's workflow and the pinboard with a few post-its |
| `notes.webp` | Issue page | A private note next to the issue's description and worklogs |
| `store.webp` | Settings → Store | The module list with one installed module and its status badge |
| `clip-fill-the-gap.mp4` | Dashboard | 30 s: open a gap, cut it, assign both pieces, the timeline fills |

Optional, if space allows: `dashboard-dark.webp` (dark theme), `mobile-dashboard.webp` (phone, 390 × 844). The older captures in `docs/screenshots/` can serve as a reference for framing.
