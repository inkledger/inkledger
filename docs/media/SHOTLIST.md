# Shot list

Screenshots and clips the [README](../../README.md) points to. These files come from the reviewed demo captures in `studio/launch-2026-11/media/` and `docs/screenshots/`.

Rules for every capture:

- Demo data only: fictional people, projects, issue keys and hosts. No real tracker URLs, names, emails or company data, in the page or in the browser chrome.
- Light theme unless noted, default density, English UI.
- WebP for stills (under 300 KB each), MP4 (H.264, no audio, under 4 MB) for clips.
- Crop the browser chrome; no notifications, cursors or personal bookmarks in sight.

| File | Screen | What it shows |
| --- | --- | --- |
| `hero.webp` | Dashboard | Day timeline with a running timer, gaps, quick stats and the issue list |
| `timeline.webp` | Dashboard, day timeline | Logged blocks from two trackers, a running timer and unlogged gaps |
| `fill-the-gap.webp` | Dashboard, a gap opened | A gap cut into two pieces, each assigned to an issue |
| `timesheet-week.webp` | Timesheet, week | A full 40-hour week by issue and day |
| `board.webp` | Board | Columns from a tracker's workflow and the pinboard with post-its |
| `issue.webp` | Issue page | Issue details, comments, worklogs and time totals |
| `reports.webp` | Reports | The trend and daily detail for a selected period |
| `clip-fill-the-gap.mp4` | Dashboard and Timesheet | 19 s: open a gap, cut it, assign both pieces, then open the timesheet; it stops before submitting the worklogs |

Optional, if space allows: `dashboard-dark.webp` (dark theme), `mobile-dashboard.webp` (phone, 390 × 844). The older captures in `docs/screenshots/` can serve as a reference for framing.
